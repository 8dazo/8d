# QPI-0C: Cross-stack transfer benchmark

This benchmark asks whether reusable physical knowledge learned across **independent quantum-dynamics implementations** reduces the measurements needed on a processor generated by a simulator family that was never present in training.

## Stacks

- **QuTiP 5.2.1**: two-level Lindblad dynamics using `mesolve`.
- **Qiskit Dynamics 0.6.0**: three-level transmon-like Lindblad dynamics using `Solver`.
- **SciPy**: direct Liouvillian matrix exponential with Gauss-Hermite averaging over quasi-static detuning, intentionally adding a non-Markovian effect absent from the shared inference model.

Every stack has a distinct processor population. The common observation protocol contains T1, Ramsey, and Rabi experiments. Source processors are calibrated densely, and the target processor is evaluated at K={4,8,16,32} measured settings.

## Strict LOFO protocol

For each held-out stack:

1. Fit source processors from the other two stacks only.
2. Learn a shared family/processor hierarchy in a common phenomenological latent space.
3. Evaluate completely unseen target processors from the held-out stack.
4. Compare target-only fitting, pooled transfer, hierarchical zero-shot transfer, 1/2-anchor family adaptation, and a same-budget validation gate.
5. Score on a separate dense evaluation grid not used for fitting.

The important test is not whether one simulator reproduces another numerically. It is whether coarse reusable physical structure survives changes in Hilbert-space dimension, solver implementation, and an intentionally mismatched noise process.

## Run

```bash
python benchmark.py --out results
```

Outputs include `summary.csv`, `per_device.csv`, `device_truth.csv`, `headline.json`, and `RESULTS.md`.
